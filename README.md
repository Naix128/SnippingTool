# 轻量截图工具

这是一个 Python + Tkinter 写的本地桌面截图软件，主要面向 Windows 使用。项目参考了常见截图工具的截图、标注、贴图、取色、图片文字识别、白板、命令行和历史记录工作流做功能兼容式实现，但不复制其他软件的代码、素材、品牌或商业版专有实现。

## 功能

- 全屏截图、活动窗口截图、鼠标框选区域截图；覆盖完整 Windows 虚拟桌面，支持左右/上下排列及负坐标副屏
- 选区内保持原亮度，选区外变暗，框选后可拖动选区和 8 个控制点缩放
- 框选前自动识别鼠标下的窗口和 Win32 原生控件，单击采用候选范围，`Tab` 可切换候选层级，拖动仍可自由框选
- 手机式长截图：自动/手动滚动采集、边采边拼、实时预览、暂停/随时完成、到底检测、质量提示及完成后上下裁剪
- 截图预览、自动保存、PNG/JPEG 输出、JPEG 质量、文件名规则、手动另存和 Windows 剪贴板复制
- 成功截图写入历史记录，可在“历史”窗口加载、复制、贴图或清空
- 使用 Windows 离线 OCR 提取中英文文字；原图上显示文字坐标框，可单击整行、拖框选择多个文字块、双击直接复制，右侧文本区支持编辑和字符级复制
- 快捷保存到独立目录，可在“首选项”里配置
- 框选工具条采用两行图标布局，上排是工具和动作，下排是线宽和调色板；图标由项目内高分辨率矢量式笔画生成
- 工具条支持矩形、椭圆、箭头、直线、画笔、高亮笔、马赛克、模糊、文字
- 文字标注支持在截图区域内透明背景直接输入，四角控制点可调整文本框和字号，完成后可拖动移动或双击重新编辑
- 支持颜色、线宽、撤销、重做、清空标注、复制、保存、贴到屏幕和取消
- 截图覆盖层带横向大尺寸像素放大镜、贯穿十字线和中心像素框，分层显示绝对坐标、RGB 与 HEX；按 `C` 可复制当前像素颜色，按 `Shift` 切换主显示格式
- 独立取色器与截图覆盖层共用像素放大镜，支持滚轮倍率、HEX/RGB 格式切换并复制颜色值
- 白板模式，可在全屏白底画布上标注、保存、复制或贴图
- 贴图按截图原屏幕坐标零边框显示，支持移动、滚轮或边缘缩放、鼠标中心缩放、透明度、吸附、缩略图、旋转、翻转、灰度、反色、取色、恢复和销毁；默认透明度、置顶、最大边长、缩略图尺寸和可恢复数量可配置
- 从剪贴板贴图：支持图片、图片文件、普通文本、颜色值文本
- Windows 系统全局热键和原生托盘菜单；关闭主窗口时可继续在托盘常驻
- 默认启动后直接隐藏到右下角系统托盘，截图完成不弹主窗口；可在“首选项”分别修改启动和截图后显示行为
- 首选项采用紧凑的主标签与二级标签布局，按常规、界面、截图、贴图、输出、控制和关于分类；支持开机启动、主题强调色、截图遮罩/边框/控制点/十字线/放大镜、输出格式与命名规则、目录管理和一键恢复默认
- 全局和窗口内快捷键可在“首选项 → 控制”中双击修改、清除禁用或恢复默认，保存前会检查重复和危险单键，并逐项显示已注册、被占用或待保存状态
- 首选项不再独占应用输入，打开设置时仍可移动、缩放和操作贴图；从设置中启动截图时会临时隐藏设置窗口
- 主窗口采用顶部截图模式、中央预览和右侧操作栏布局，窄窗口下不再挤压或截断按钮文字
- 命令行触发截图、贴图、取色、白板、显示/隐藏贴图、清空历史、打开首选项

## 快捷键

主窗口：

以下为默认组合键，可在“首选项 → 控制”中自定义。标记为全局的快捷键在启用系统全局快捷键后无需主窗口获得焦点；被其他截图软件占用的组合键会自动跳过。

默认后台模式下无需打开主窗口：托盘图标左键可开始框选截图，右键可打开截图、贴图、历史、首选项和退出菜单。

- `Ctrl+Shift+F`：全屏截图
- `Ctrl+Shift+W`：活动窗口截图
- `Ctrl+Shift+A`：框选区域
- `Ctrl+Shift+L`：开始长截图；采集中再次按下可直接完成
- `Ctrl+Shift+C`：取色
- `Ctrl+Shift+B`：白板
- `F3`：从剪贴板贴图
- `Shift+F3`：显示/隐藏全部贴图
- `Ctrl+T`：把当前图片贴到屏幕
- `Ctrl+Shift+S`：快捷保存
- `Ctrl+Shift+P`：首选项
- `Ctrl+S`：另存为
- `Ctrl+C`：复制当前图片
- `Ctrl+Shift+O`：提取当前图片文字

截图/白板覆盖层：

- `Enter` / 工具栏复制按钮：完成截图并复制到剪贴板
- `Ctrl+C`：完成并复制
- `Ctrl+S`：完成并保存
- `Ctrl+T`：完成并贴到屏幕
- `Esc`：清除选区或退出
- `Space`：显示/隐藏工具条
- 单击高亮候选：选中窗口/控件；拖动：自由框选；`Tab`：切换候选层级或切换直线/箭头
- 鼠标滚轮 / `1` / `2`：调整当前标注线宽
- 按住 `Shift` 绘制：约束为正方形、圆或 45 度方向
- 选择矩形、椭圆、马赛克或模糊后右键：按鼠标下控件范围快速标注
- `Alt`：强制显示放大镜；`C`：复制当前像素颜色；鼠标中键：完成并贴图
- `Ctrl+Z` / `Ctrl+Y`：撤销/重做标注
- `Ctrl+Shift+Z`：清空全部标注
- 文字编辑框内 `Enter`：换行
- 文字编辑框内 `Ctrl+Enter`：确认文字
- 文字编辑框内 `Esc`：取消文字
- `W A S D`：逐像素移动鼠标指针
- 未建立选区时，`↑ ← ↓ →`：逐像素移动取色十字光标
- 建立选区后，`↑ ← ↓ →`：移动选区
- `Ctrl + ↑ ← ↓ →`：扩大选区
- `Shift + ↑ ← ↓ →`：缩小选区
- 鼠标双击选区：完成并复制
- 鼠标右键：重新选择或退出

贴图窗口：

- 鼠标拖动：移动贴图
- 鼠标滚轮 / `+` / `-` / 拖动边缘：缩放贴图
- `Ctrl + 鼠标滚轮` / `Ctrl + +` / `Ctrl + -`：调整透明度
- `Shift + 拖动`：吸附屏幕边缘或其他贴图
- `Shift + 双击`：切换缩略图模式
- `C`：复制鼠标所在像素颜色
- `1` / `2`：顺/逆时针旋转 90 度
- `3` / `4`：水平/垂直翻转
- `5` / `6`：灰度/反色
- `Esc` / `Ctrl+W` / 双击：关闭，可恢复
- `Shift+Esc`：销毁，不进入恢复列表
- 鼠标右键：打开贴图菜单
- 右键菜单“提取文字”：识别当前贴图经过旋转、翻转、灰度或反色后的画面
- `保持置顶`：关闭后贴图按普通窗口层级显示，可能被其他窗口遮挡
- 鼠标中键：重置大小和透明度

## 图片文字

主窗口“当前图片”、截图历史和贴图右键菜单均可打开“提取文字”。识别在后台执行，不会阻塞截图或其他贴图操作。

- 左侧原图：单击选择一行，拖动框选多个文字块，双击一行直接复制；聚焦原图后可用 `Ctrl+C` 复制选中内容
- 右侧文本：支持普通文本编辑、拖选和 `Ctrl+C`，也可点击“复制选中”或“复制全部”
- 原图支持缩放、适应窗口和滚动查看，识别框会随缩放保持在对应位置
- OCR 使用 Windows `Windows.Media.Ocr`，离线运行；需要系统安装相应 OCR 语言能力，当前默认优先使用简体中文
- Windows OCR 最大输入边长为 10000 像素，超过时会等比缩小并把识别坐标映射回原图

## 长截图

点击“长截图”后选择采集方式，再框选网页、文档、聊天记录或代码编辑器里的可滚动内容区域。采集期间会显示独立浮窗，实时展示最新拼接内容、总尺寸、段数和接缝质量，可暂停、继续、完成或取消。程序会在每次采集后立即拼接，不需要在结束时长时间等待。

- 自动滚动：程序发送滚轮事件并在画面稳定后采集，检测到页面到底会自动完成
- 手动滚动：用户自行滚动目标窗口，程序只在画面停止变化后采集，适合聊天记录、懒加载页面和特殊滚动控件
- 再次按 `Ctrl+Shift+L` 或点击浮窗“完成”，可随时保留当前已经可靠拼接的内容
- 完成后进入长图结果页，可滚动查看，并在右侧全图轨道拖动上下手柄裁剪，再选择完成、复制、保存或贴图
- 固定标题栏和固定底栏会参与静态区域检测，底栏只在最终图片中保留一次；无法可靠匹配时停止并保留此前结果

使用建议：

- 选区尽量只包含可滚动内容，不要包含浏览器地址栏、软件标题栏等固定区域
- 如果页面有固定表头或悬浮按钮，缩小选区避开它们可以减少重复
- 自动滚动期间不要操作目标窗口；需要自己控制滚动时选择“手动滚动”
- 当前长截图依赖 Windows 鼠标滚轮事件，目标区域必须能响应滚动

## 命令行

在当前目录下可直接运行：

```powershell
python screenshot_app.py snip --full -o clipboard
python screenshot_app.py snip --active-window -o pin
python screenshot_app.py snip --area 100 100 800 500 -o quick-save
python screenshot_app.py paste
python screenshot_app.py paste --plain "要贴到屏幕的文本" --pos 300 200
python screenshot_app.py paste --files "D:\Pictures\a.png" "D:\Pictures\b.png"
python screenshot_app.py pick-color
python screenshot_app.py whiteboard --color white
python screenshot_app.py toggle-images
python screenshot_app.py clear-snip-history
python screenshot_app.py open-preferences
```

`snip` 支持的输出：

- `-o clipboard`：复制截图
- `-o pin`：贴到屏幕
- `-o quick-save`：保存到快捷保存目录
- `-o file-dialog`：打开另存为对话框
- `-o no-auto-save`：不触发自动保存
- `-o success` / `-o silent`：只记为成功截图
- `-o 文件路径`：保存到指定路径

## 运行

在 VS Code 集成终端中进入当前目录后执行：

```powershell
python screenshot_app.py
```

程序默认启动到右下角系统托盘，并保持全局快捷键可用。需要主窗口时，右键托盘图标选择“显示主窗口”。“首选项”提供以下独立开关：

- `登录 Windows 后自动启动`：写入当前用户启动项，不要求管理员权限
- `启动时隐藏到系统托盘`：关闭后每次启动显示主窗口
- `截图结束后显示主窗口`：开启后每次截图结束弹出主窗口，关闭后继续留在托盘
- `关闭主窗口时最小化到托盘`：关闭后点击主窗口关闭按钮会退出程序

“截图”页可调整遮罩深度、选区边框、控制点、十字线、放大镜和默认倍率；“贴图”页可设置最大边长与快捷缩略图尺寸；“输出”页支持 PNG/JPEG、JPEG 质量以及 `{yyyy}`、`{MM}`、`{dd}`、`{HH}`、`{mm}`、`{ss}` 文件名令牌。

如果提示缺少 Pillow，先执行：

```powershell
python -m pip install -r requirements.txt
```

## 打包成 exe

可选安装 PyInstaller：

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconsole --onefile --name ScreenshotTool screenshot_app.py
```

打包完成后，程序在 `dist/ScreenshotTool.exe`。

## 当前边界

- 贴图分组管理器、打印机输出、二维码/条形码识别、文本旋转等尚未实现
- 自动识别当前覆盖顶层窗口和传统 Win32 子控件；浏览器 DOM、Electron 内部节点和复杂 UI Automation 元素不保证逐层识别
- 全局热键若已被 Snipaste 或其他软件占用会注册失败，对应组合键仍可在主窗口获得焦点时使用
- 命令行 HTML 贴图目前会转为纯文本贴出，不做浏览器级 HTML 渲染
- 长截图不是浏览器协议级滚动截图，而是模拟鼠标滚轮采集，复杂页面可能需要调整选区和等待时间
- 本项目只复现通用工作流并使用原创图标和实现，不包含 Snipaste 的代码、二进制资源、品牌素材或商业版专有能力

## 移除方式

删除 `screenshot_app.py`、`requirements.txt`、`README.md`，以及运行后生成的 `screenshots`、`quick-save`、`history`、`screenshot_settings.json` 即可。
